## Built for repair decisions

Low-Budget Repairs rewards smart spending as much as fast work. RepairCalc gives each project a place to estimate material needs, compare repair scopes, record the outcome, and spot the jobs that delivered the best return for the time invested.

<p align="center">
  <strong>Plan</strong> &nbsp;→&nbsp; <strong>Compare</strong> &nbsp;→&nbsp; <strong>Complete</strong> &nbsp;→&nbsp; <strong>Review</strong>
</p>

## What is included

### Cost and material planning

- Create a project for a room, apartment, or custom repair order.
- Add materials, quantities, and personal material presets.
- Review the expected cost before committing to a plan.
- Compare several repair scopes without rebuilding the list each time.

### Results and progress

- Record completed orders with time, materials, and final payout.
- Sort job history by profit, margin, or time spent.
- Review profit per minute across current and completed projects.
- Set collection-style goals for materials, room types, and preferred job targets.

## Installation

1. Download `Installer.zip` using the link above.
2. Extract the downloaded archive.
3. Open RepairCalc from the extracted folder.
4. Create the first project and add the materials you plan to use.

## Quick start

1. Select **New Project** and enter the repair target.
2. Add material quantities or load one of the saved material sets.
3. Check the cost and expected payout on the project overview.
4. Use **Plan Comparison** to evaluate budget, standard, and expanded options.
5. Finish the job, save the result, and review it in **Job History**.

## Requirements
